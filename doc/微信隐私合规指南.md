# 微信小程序隐私合规指南

> 截止日期：**2026年2月12日**
> 小程序：三条AAA盲注 (wxa5a5af3fc76a9f8e)

---

## 📋 需要完成的操作

### 步骤一：登录微信公众平台

1. 访问 [mp.weixin.qq.com](https://mp.weixin.qq.com)
2. 使用管理员微信扫码登录
3. 进入小程序管理后台

---

### 步骤二：填写隐私保护指引

**路径**：设置 → 基本设置 → 服务内容声明 → 用户隐私保护指引

**需要填写的内容**：

#### 1. 收集的用户信息类型

根据您的小程序功能，勾选以下信息：

| 信息类型 | 用途说明 | 是否收集 |
|---------|---------|---------|
| **微信昵称** | 用于会员展示和社交互动 | ✅ 是 |
| **微信头像** | 用于会员个人主页展示 | ✅ 是 |
| **手机号码** | 用于会员注册和身份验证 | ✅ 是 |
| **位置信息** | 不收集 | ❌ 否 |
| **相册/相机** | 不收集 | ❌ 否 |

#### 2. 信息使用说明（参考文本）

```
本小程序收集您的微信昵称、头像和手机号码，用于：
1. 会员账户注册与登录
2. 个人主页展示
3. 牌桌预约和订单管理
4. 积分排行榜展示

我们承诺：
- 不会将您的个人信息用于上述目的之外的用途
- 不会向第三方共享、出售您的个人信息
- 您可以随时联系我们删除您的账户和相关信息
```

#### 3. 开发者联系方式

填写您的联系邮箱或客服电话，供用户咨询隐私问题。

---

### 步骤三：小程序代码配置

需要在 `app.json` 中添加隐私协议配置：

```json
{
  "__usePrivacyCheck__": true
}
```

---

### 步骤四：提交审核

完成隐私保护指引填写后：
1. 点击"保存"
2. 如有代码更新，需重新提交审核
3. 审核通过后即完成合规
