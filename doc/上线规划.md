## 🚀 五、上线后运维

### 日常监控
```bash
# 查看服务状态
pm2 status

# 查看 API 日志
pm2 logs texas-api

# 查看 Admin 日志
pm2 logs texas-admin

# 重启服务
pm2 restart all
```

### 数据库备份
```bash
# 手动备份
mysqldump -u root -p texas_mp > backup_$(date +%Y%m%d).sql

# 建议配置定时任务，每天自动备份
```

### 常见问题排查

| 问题 | 排查命令 |
|------|---------|
| API 无响应 | `pm2 logs texas-api --lines 100` |
| 数据库连接失败 | 检查 `.env` 和 MySQL 服务状态 |
| Redis 连接失败 | `redis-cli ping` |
| 端口被占用 | `netstat -tlnp | grep 3000` |
