# 后端服务部署快速指南 (WinSCP + PuTTY)

> 本文档提供基于 WinSCP 文件传输 + PuTTY 命令执行的后端服务重新部署步骤。

---

## � 部署步骤

### 第一步：本地构建

在本地 VS Code 终端中执行：

```bash
cd apps/server
npm run build
```

构建成功后，`apps/server/dist` 目录会生成最新的编译产物。

---

### 第二步：WinSCP 上传文件

1. **打开 WinSCP**，连接到服务器 `dezhoubar.xyz`

2. **导航到服务器目录**：
   ```
   /home/ubuntu/texas-miniprogram/apps/server/
   ```

3. **上传以下内容**（从本地 `apps/server/` 目录）：
   - ✅ 整个 `dist/` 文件夹（覆盖上传）
   - ✅ `package.json`（如果有依赖变更）
   - ✅ `package-lock.json`（如果有依赖变更）

4. **确认覆盖**：选择"全部是"覆盖现有文件

---

### 第三步：PuTTY 重启服务

1. **打开 PuTTY**，连接到服务器

2. **执行以下命令**：

```bash
# 如果有新依赖，先安装
cd /home/ubuntu/texas-miniprogram/apps/server
npm install

# 重启服务
pm2 restart texas-server
```
pm2 restart all
3. **验证服务状态**：

```bash
pm2 status
pm2 logs texas-server --lines 20
```

看到 `online` 状态且无报错即部署成功。

---

## � 快速版（无依赖变更时）

如果只是修改了业务代码，没有新增 npm 包：

**本地**：`npm run build`

**WinSCP**：上传 `dist/` 文件夹

**PuTTY**：`pm2 restart texas-server`

---

## ⚠️ 故障排查

### 服务无法启动

```bash
pm2 logs texas-server --err --lines 50
```

### 找不到模块错误

说明有新依赖没安装，执行：

```bash
cd /home/ubuntu/texas-miniprogram/apps/server
npm install
pm2 restart texas-server
```

### 需要完全重新部署

```bash
pm2 delete texas-server
cd /home/ubuntu/texas-miniprogram/apps/server
pm2 start dist/main.js --name texas-server
pm2 save
```
